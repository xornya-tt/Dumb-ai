Дима — глупый ИИ-человек (Kotlin + Jetpack Compose)

1. Android Studio -> File -> Open -> выбери папку DumbAI
2. Дождись Gradle Sync (нужен интернет, скачает Gradle 8.9 и библиотеки)
3. Run на эмуляторе или телефоне

Нужен JDK 17 (встроенный в Android Studio подходит). minSdk 26 (Android 8.0+).
Иконка: app/src/main/res/drawable/ic_launcher_foreground.xml
Цвет фона иконки: app/src/main/res/values/ic_launcher_background.xml
